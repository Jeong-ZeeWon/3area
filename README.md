# 교구 출석 체크 (Google Apps Script)

구글 스프레드시트로 관리하는 **지역별 주일 출석부**를 지역장들이 휴대폰에서 바로 체크할 수 있게 만든 웹앱입니다.
체크하면 1초 안에 원본 시트의 해당 날짜 칸에 기록되고, 여러 지역장이 동시에 작업해도 서로의 기록을 덮어쓰지 않습니다.

- 서버·데이터베이스가 따로 필요 없습니다. 스프레드시트 자체가 데이터베이스입니다.
- 지역장에게는 본인 지역 전용 링크만 보내면 됩니다.
- 시트에 월을 더하거나 순원을 넣고 빼도 **코드를 고칠 필요가 없습니다**. 표 구조를 매번 읽어 들입니다.

## 화면

| 지역 선택 | 출석 체크 |
| --- | --- |
| 지역마다 고유 색상 타일, 지역장 이름 표시 | 날짜 칩, 출석률 링 게이지, 순별 카드 명단 |

주요 기능은 다음과 같습니다.

- 오늘 날짜에 가장 가까운 주일이 자동 선택됩니다.
- 이름 줄을 누르면 체크되고 자동 저장됩니다(약 0.9초 지연 후 묶어 전송).
- 순 단위 일괄 체크, 지역 전체 체크·해제
- 출석률 링 게이지와 순별 진행 바
- 미출석 명단 한 번에 복사(심방·연락용)
- 연락처를 누르면 바로 전화 연결
- 저장 실패 시 체크 내용이 남아 있어 다시 보낼 수 있습니다
- 다크 모드 지원

## 요구되는 시트 구조

지역마다 탭 하나를 쓰고, 각 탭은 다음 형태여야 합니다.

|  | A | B | C | D | E | … |
| --- | --- | --- | --- | --- | --- | --- |
| **1행** | `3교구_1지역` (A~C 병합) | | | `9월` (4칸 병합) | | `10월` … |
| **2행** | `구분` | `순원` | `연락처` | `6` | `13` | … |
| **3행** | `지역장` | 홍길동 | 010-0000-0000 | | | |
| **4행** | `1순` | 김○○ | 010-… | | | |
| **5행** | | 이○○ | 010-… | | | |

- 인식 기준은 **A열 `구분` + B열 `순원`** 이 함께 있는 행입니다. 그 행이 머리글이 되고, 바로 위 행에서 월을 읽습니다.
- 병합된 월 표시는 첫 칸에만 값이 있으므로 오른쪽으로 이어서 채워 해석합니다.
- A열에 값이 나오면 새 순(그룹)이 시작되고, B열에 이름이 있는 행만 순원으로 잡습니다. 순 사이 빈 행은 무시됩니다.
- 날짜 열은 D열부터 마지막 열까지 자동으로 탐색합니다. 숫자여도 날짜 서식이어도 됩니다.
- 이 구조가 아닌 탭(집계표, 안내 시트 등)은 자동으로 건너뜁니다.

## 설치

1. 출석부 스프레드시트에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 기본 `Code.gs` 를 [`src/Code.gs`](src/Code.gs) 내용으로 바꿉니다.
3. **파일 추가 → HTML** 로 파일을 만들고 이름을 정확히 `Index` 로 지정한 뒤 [`src/Index.html`](src/Index.html) 내용을 붙여 넣습니다.
4. 저장한 뒤 **배포 → 새 배포 → 웹 앱** 을 선택하고, 실행 계정은 `나`, 액세스 권한은 `모든 사용자` 로 두고 배포합니다.
5. 첫 배포에서는 권한 승인 화면이 나옵니다. **고급 → 안전하지 않은 페이지로 이동** 을 눌러 승인합니다.

1단계처럼 **시트에서** Apps Script 를 열면 스크립트가 그 시트에 붙으므로 시트 ID를 적을 필요가 없습니다. 반대로 script.google.com 이나 드라이브에서 새 프로젝트를 만든 **독립 스크립트**라면 `SpreadsheetApp.getActiveSpreadsheet()` 가 `null` 이 되어 `Cannot read properties of null (reading 'getSheets')` 오류가 납니다. 이때는 `setSpreadsheetId()` 함수 안의 `id` 에 출석부 시트 ID를 넣고 편집기에서 한 번 실행하면 스크립트 속성에 저장되어 정상 동작합니다. 독립 스크립트에서는 시트 상단 메뉴가 생기지 않으므로, `makeRegionLinks` 와 `checkStructure` 는 편집기의 함수 실행으로 돌리고 결과는 실행 기록에서 확인하십시오.

clasp 를 쓴다면 `.clasp.json.example` 을 `.clasp.json` 으로 복사하고 스크립트 ID를 넣은 뒤 `clasp push` 하면 됩니다.

## 배부

배포 후 스프레드시트를 새로 고치면 상단에 **출석 체크 앱** 메뉴가 생깁니다.

- **지역장 배부 링크 만들기** — `_배부링크` 시트에 지역별 전용 링크(`…/exec?r=탭이름`)를 정리해 줍니다. 이 링크를 받은 지역장은 지역 선택 화면 없이 본인 지역 명단이 바로 열립니다.
- **출석부 구조 점검** — 각 지역의 순 개수, 인원, 인식된 날짜 범위를 한눈에 확인합니다. 처음 설치했을 때 먼저 실행해 보시길 권합니다.

## 설정

`src/Code.gs` 상단 `CONFIG` 에서 조정합니다.

| 항목 | 설명 |
| --- | --- |
| `SPREADSHEET_ID` | 비워 두면 스크립트가 붙어 있는 시트를 사용합니다. 다른 파일을 쓸 때만 스크립트 속성 `SPREADSHEET_ID` 에 넣으세요. |
| `APP_TITLE` | 앱 제목 |
| `MARK` | 출석 표시 문자. 기본 `O` |
| `FIRST_DATE_COL` | 날짜가 시작되는 열 번호. 기본 `4`(D열) |
| `USE_ACCESS_CODE` | `true` 로 두면 지역별 접속코드를 입력해야 명단이 열립니다 |
| `ENABLE_LOG` | 누가 언제 무엇을 바꿨는지 숨은 `_변경기록` 시트에 남깁니다 |

접속코드를 쓰려면 `setAccessCodes()` 안의 표를 교회 상황에 맞게 고친 뒤 편집기에서 한 번 실행하세요. 코드는 스크립트 속성에 저장되며 소스 코드에는 남지 않습니다.

## 개인정보에 관한 주의

이 저장소에는 **실제 명단과 스프레드시트 ID가 들어 있지 않습니다.** 코드만 공개되어 있습니다. 포크하거나 수정해 쓰실 때도 다음을 지켜 주십시오.

- 교인 이름·연락처가 담긴 시트 ID, 배포 URL, 접속코드를 커밋하지 마십시오.
- 웹앱 액세스 권한을 `모든 사용자` 로 두면 링크를 아는 누구나 명단을 볼 수 있습니다. 링크 관리가 어렵다면 `USE_ACCESS_CODE` 를 켜거나, 액세스 권한을 조직 내부로 제한하십시오.
- 지역장이 바뀌면 링크를 다시 만들어 배부하고 이전 링크 사용을 정리해 주십시오.

## 기술 메모

- 저장은 날짜 열 단위로 묶어 `getValues → 수정 → setValues` 한 번에 처리하므로 체크를 여러 개 해도 호출이 가볍습니다.
- 동시 편집 충돌은 `LockService` 로 막고, 대상 칸 외에는 손대지 않습니다.
- 클라이언트가 보낸 행·열 번호는 서버에서 실제 명단 범위와 대조해 검증한 뒤에만 기록합니다.
- 화면은 순수 HTML·CSS·JS 입니다. 외부 의존성은 Google Fonts(Noto Sans KR) 하나뿐입니다.
